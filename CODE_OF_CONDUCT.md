# Code of Conduct

This project follows a simple standard: be respectful, assume good faith, and
keep discussion focused on the technical issue at hand.

- Harassment, personal attacks, and discriminatory language/jokes are not
  welcome in issues, PRs, or discussions.
- Disagree with a technical decision by arguing the technical point, not the
  person.
- Maintainers may close, lock, or edit issues/PRs/comments that violate this,
  and may block repeat offenders.

If you experience or witness unacceptable behavior in this project's spaces,
report it to kunwarsingh040126@gmail.com. Reports are handled confidentially.

This is a condensed policy; for a fuller reference see the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
