# Getting help

- **How do I use it?** Start with the [README](README.md) and `orbiitl-check --help`.
  [docs/fixing-findings.md](docs/fixing-findings.md) explains how to fix each finding.
- **What does a finding mean?** See [docs/checks.md](docs/checks.md).
- **Found a bug or want a feature?** Open an issue using the templates in
  `.github/ISSUE_TEMPLATE`. Please redact any real target in what you paste.
- **Found a vulnerability in orbiitl-check itself?** Do not open a public issue;
  follow [SECURITY.md](SECURITY.md).

This is a volunteer-maintained project; responses are best effort.

orbiitl-check is for education and for auditing systems you own or are
explicitly authorized to test. We can't help with scanning systems you don't
have permission to test.
